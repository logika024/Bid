# Resume Tailor — ATS Job Resume Generator

A Chrome extension (Manifest V3) that writes a complete, ATS-optimized resume
PDF from your profile + a pasted job description, and saves it straight into a
folder you choose.

## How it works

1. **One-time setup:** you fill in a profile — contact details, total years of
   experience, your roles (company, title, location, dates, optional notes),
   and education. No resume upload needed.
2. **Per job:** you paste a job description. GPT writes the full resume —
   professional summary, technical skills, and 3-5 achievement bullets per role
   — tailored to the JD for a high ATS keyword match.
3. The resume is rendered into a real text-based PDF (selectable text, which
   ATS parsers need) using a fixed template.
4. The PDF is saved into your chosen folder, named
   `company_job-title_timestamp.pdf`.

Section order is fixed: **Professional Summary → Technical Skills → Experience
→ Education.**

### Important: facts vs. generated content

- **Never changed:** your name, contact info, company names, job titles,
  locations, employment dates, schools, and degrees come straight from your
  profile and are locked.
- **Generated by GPT:** the summary, the skill groupings, and every bullet.
  Without per-role notes, GPT writes realistic, role-typical bullets with
  plausible metrics — **always review and correct these before sending.** Add
  notes to each role (real projects, scope, numbers) for accurate, grounded
  bullets.

## Install (load unpacked)

1. Open `chrome://extensions` in Chrome or Edge.
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked** and select the `resume-tailor` folder.
4. Pin the extension.

## First-time setup

Open the extension → **⚙ Settings**:

1. **OpenAI** — API key (`sk-…`) and model (`gpt-4o` recommended).
2. **Save folder** — click **Choose folder…** and pick any directory; every
   PDF is written there. Chrome may ask you to re-allow the folder once after a
   browser restart.
3. **Your details** — name, years of experience, contact info, optional skills.
4. **Work experience** — add each role; notes are optional but strongly
   recommended for accurate bullets.
5. **Education** — add your degrees.
6. **Generation prompt** — pre-filled with the recommended prompt; editable.

Click **Save Settings**.

## Daily use

1. Click the extension icon.
2. Paste the full job description.
3. Click **Generate & Save Resume** — the PDF lands in your folder.
4. A **Download a copy** button also saves it to your Downloads folder.

Keep the popup open while it generates (~15–40 s) — closing it cancels the run.

## Privacy

API key and profile are stored locally (`chrome.storage.local`); the folder
handle is stored in the extension's IndexedDB. Profile data and the job
description are sent to the OpenAI API to generate the resume — nothing else
leaves your machine.

## Project layout

| Path | Purpose |
|------|---------|
| `manifest.json` | MV3 manifest |
| `popup.*` | JD input, generate, save/download UI |
| `options.*` | Settings, profile form, folder picker |
| `src/constants.js` | Generation prompt + output contract |
| `src/storage.js` | `chrome.storage` wrapper |
| `src/fs.js` | Folder handle persistence + file writing (File System Access API) |
| `src/openai.js` | OpenAI call that generates resume content |
| `src/pdf-template.js` | Resume object → pdfmake PDF + file naming |
| `lib/` | Bundled pdfmake |

## Browser support

Saving into a chosen folder uses the File System Access API
(`showDirectoryPicker`), available in Chrome and Edge. In browsers without it,
the folder picker is disabled — use the **Download a copy** button instead.
